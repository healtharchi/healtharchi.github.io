Mistral Large 4をオープンウェイトで公開

Mistral AIがMistral Large 4の重みを公開しました。修正MITライセンスで商用利用でき、API価格は入力$0.70 / M・出力$2.10 / M。自社ホストやコーディングエージェントのモデル選定に関係します。

何が発表されたか

Mistral AIは、旗艦モデルMistral Large 4（愛称 Le Chonk）の重み（weights）を公開しました。今月初めにpublic previewとして出していたモデルに、追加の強化学習でコーディングと防御的サイバーセキュリティの改善を加えたものです。1兆（1-trillion）パラメータのネイティブマルチモーダルモデルで、ヨーロッパのインフラでゼロから訓練したとしています。

提供条件と費用は次のとおりです（出典の公開時点）。

  • 入手先: Mistral Studio、Mistral API、OpenRouter。重みはHugging Faceから取得し、vLLMかSGLangで自社のインフラに展開できます。マネージドサービスとしてはMicrosoft Foundryでも提供されます。
  • ライセンス: Mistral Ecosystem Open-Weight license（修正MITライセンス）。利用・改変・ファインチューニング・商用化は自由です。ただし、Model-as-a-Serviceを運営する事業者だけは、商用利用の前にMistralから別途商用ライセンスを得る必要があります。
  • API価格: 入力 $0.70 / M、キャッシュ入力 $0.07 / M、出力 $2.10 / M トークン。
  • 推論モード: Low・Medium・High（既定）の3段階。Lowは従来の「None」モードを置き換えます。

Mistralが示した主な数値は、すべてMistral自身の発表です。

  • コーディング: CognitionのFrontierCode 2.0で19.7%。Artificial Analysis Coding Agent Indexで48%（GLM-5.3と実質同点で、タスクあたりのトークン使用量は平均47%少ない）。Terminal-Bench 4.0はpreview時から13ポイント上がって41%、出力トークンは30%減。
  • セキュリティ: Artificial Analysis Cyber Indexで51%。悪意あるサイバー関連の要求の平均拒否率は96.6%。B3 Agent Security Benchmarkでは攻撃の97.1%に耐え、preview時の93.3%から向上。

誰に関係するか

  • コーディングエージェントを使う開発者: オープンウェイトのモデルの選択肢が増えます。Mistralは、Surge Codeのブラインド比較でGLM-5.3・Kimi K3・DeepSeek V4.1 Flashより好まれ、評価対象の中ではClaude Opus 5.5にのみ及ばなかったとしています。自社のコードで確かめる価値はあります。
  • 自社ホストを検討する企業のIT部門: 重みをHugging Faceから取得して自社のインフラで動かせます。APIに依存せず運用したい場合の候補になります。Model-as-a-Serviceとして他社に提供する場合はライセンス条件に注意が必要です。
  • セキュリティ部門: 脆弱性の発見・再現・修正を測るCyber Indexの数値と、悪意ある要求の拒否率が示されています。一方で、Mistralはpreview以降の利用状況の監視で実際の攻撃に使われる可能性を認め、ガードレールを修正中としています。
  • 一般利用者: 影響は小さいです。

今日できること

  • Hugging Faceのモデルカードとライセンス（Mistral Ecosystem Open-Weight license）を読み、自社の用途がModel-as-a-Serviceに当たらないか確かめる。
  • Mistral Studio、Mistral API、OpenRouterのいずれかで、Low・Medium・Highの推論モードを切り替えて、自社のタスクで結果とトークン消費を比べる。
  • 自社ホストする場合は、Hugging Faceから重みを取得し、vLLMかSGLangで展開する。マネージドで使うならMicrosoft Foundryを確認する。
  • 入力 $0.70 / M、キャッシュ入力 $0.07 / M、出力 $2.10 / M の単価を、今使っているモデルの単価と並べて比べる。

注意点

  • 日本での提供条件は出典に記載なしです。
  • ベンチマークの数値はMistralの発表によるもので、自社の作業で同じ結果になるとは限りません。オープンウェイトでコーディングの最上位という位置づけもMistralの自己申告です。
  • 技術レポートは近日公開とされており、本記事の時点では未公開です。
  • サイバーセキュリティ向けに最適化した派生版は、Orange Cyberdefenseなどの設計パートナーへの限定previewで、審査と契約上の制約があります。
