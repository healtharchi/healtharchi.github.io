Anthropic、防御側支援のCyber Mission開始

Anthropicが重要インフラとオープンソースを守る長期計画 Anthropic Cyber Mission を開始。OSSを無償で定期スキャンするOSS Scannerと11社参加の重要インフラ防御プログラムが柱。日本の条件は記載なし。

対象:セキュリティ担当者オープンソースのメンテナ企業のIT部門

△
判定: 様子見
Critical Infrastructure Defense Program は創設パートナー11社の少数グループから始まる限定的な取り組みで、OSS Scanner も指摘に対応する余力のあるオープンソースプロジェクト向けのオプトイン型です。日本での提供条件は出典に記載がなく、一般の企業がすぐ導入する製品ではありません。

何が発表されたか

Anthropic は 2026年10月8日、Anthropic Cyber Mission を発表しました。防御側にツール・研究・資源を提供し、重要インフラとオープンソースソフトウェアを守る長期的な取り組みです。初期の対象は次の2領域です。

  • 重要インフラ: Critical Infrastructure Defense Program（CIDP）を開始。電力網・水道・交通網を支える運用技術（OT）を守る事業者に、フロンティアモデル、現地常駐のエンジニア、脅威研究を提供します。創設パートナーは Accenture、Booz Allen、CrowdStrike、Deloitte、Dragos、Hitachi、Insane Cyber、Nozomi Networks、Palo Alto Networks、PwC、Rockwell Automation の11社です。
  • オープンソース: OSS Scanner を開始。オプトイン型のサービスで、登録したプロジェクトは最上位モデルによる定期的なセキュリティスキャンを無償で受けられます。レポートには悪用方法の概念実証、説明、可能な場合は修正案が含まれます。

今週初めには Project Glasswing が拡張された Cyber Verification Program に統合されました。

誰に関係するか

  • セキュリティ担当者・重要インフラの事業者: CIDP は OT を守る「信頼された事業者」向けです。まずは少数の事業者グループと協働し、どの戦略が有効で実用的かを学ぶ段階だとしています。あらゆる規模のセキュリティチームは Cyber Verification Program に申請できます。
  • オープンソースのメンテナ: 重要なプロジェクトのコアメンテナは OSS Scanner に登録できます。対象は指摘に対応する余力のあるプロジェクトです。無償の Claude Max サブスクリプションを Claude for Open Source に申請することもできます。
  • セキュリティ製品・サービス企業: 重要インフラ向けの製品やサービスを持つ企業は、CIDP の拡大に向けて関心登録ができます。
  • 一般利用者・一般の企業: 直接の影響は小さいです。

今日できること

  • 重要インフラ向けのセキュリティ製品・サービスを提供している企業は、Critical Infrastructure Defense Program に関心登録する
  • 重要なオープンソースプロジェクトのコアメンテナは、指摘に対応する余力があるかを確認したうえで OSS Scanner に登録する
  • オープンソースのメンテナは Claude for Open Source に、無償の Claude Max サブスクリプションを申請する
  • セキュリティチームは Cyber Verification Program に申請し、防御目的での Claude の利用枠を広げる

注意点

  • OSS Scanner のレポートはモデルが生成し、人のレビューを経ずに送られます。誤った深刻度評価などの不正確さを含む場合があると Anthropic 自身が明記しています。真陽性率は 90% 超を「見込む」としており、実績値ではありません。
  • 余力のないプロジェクトには、従来どおり人が検証した開示を CVD ポリシーのもとで続けるとしています。
  • OSS Scanner は Google の OSS-Fuzz に着想を得たサービスで、無償です。8月に開始した Defender Advantage Fund（0xDAF）が支えています。CIDP の費用に関する記述は出典にありません。
  • 日本からの利用可否や提供地域の記述は出典にありません。
  • 6月に始めた州・地方・部族・準州政府向けのサイバー防御プログラムでは、米国の州の半数以上と大規模な公共重要インフラ事業者にフロンティア Claude モデルと技術支援を提供してきたと述べています。
  • Anthropic は 2年後には AI が防御側に有利になると予測する一方、近い将来はそうでない可能性があるとも述べています。Project Glasswing では、脆弱性の発見から修正まで数か月かかることが多かったとしています。
