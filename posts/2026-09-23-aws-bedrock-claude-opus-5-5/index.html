何が発表されたか

AWS は 2026年9月22日、Anthropic の Claude Opus 5.5 を Amazon Bedrock と Claude Platform on AWS で提供開始したと発表しました。Claude 5.5 ファミリーの最初のモデルです。

費用面の説明（いずれも Anthropic の主張として紹介されています）:

  • Claude Opus 5 より少ないトークンで多くの作業をこなす
  • トークン単価の引き下げと、キャッシュ読み取りの大幅な値下げが加わる
  • その結果、タスクあたりの平均コストが Opus 5 より低くなる

具体的な単価はこの発表に記載がなく、Amazon Bedrock pricing を参照するよう案内されています。

使い方の変更点:

  • Adaptive thinking（推論量をモデルが自分で決める仕組み）が常時オンです。手動の thinking budget の代わりに effort で制御します。
  • 生物学・サイバーセキュリティ・AI 開発の分野で、Claude Fable 5.1 に似た安全分類器を備えた最初の Opus です。従来の Opus よりリクエストが拒否される頻度が高くなると明記されています。

提供条件（出典に記載の時点）:

提供経路 条件
Bedrock（bedrock-runtime） US／EU／AU／JP の Geo CRIS と Global CRIS の推論プロファイル
Bedrock（bedrock-mantle） us-east-1、ap-southeast-4
Claude Platform on AWS 北米

JP Geo CRIS の推論プロファイルは、接頭辞 jp. と記載されています。

誰に関係するか

  • 開発者（Bedrock で Claude を使っている人）: 新しいモデル ID への切り替えを検討する対象です。Anthropic Messages API（bedrock-runtime と bedrock-mantle）と、従来の Invoke／Converse API の両方で呼べます。
  • 企業のIT部門: Bedrock の推論プロファイルに JP Geo CRIS（jp.）が含まれています。Claude Platform on AWS は北米のみです。
  • 費用管理の担当者: 単価引き下げとキャッシュ読み取りの値下げが示されていますが、金額は出典に記載なしです。見積もりは Amazon Bedrock pricing で確認が必要です。
  • 生物学・セキュリティ・AI 開発の業務: 拒否が増えると明記されているため、影響を受けやすい層です。

今日できること

  • Amazon Bedrock コンソールで Test → Playground を開き、Claude Opus 5.5 を選んで、いま使っているプロンプトを試す。
  • API から呼ぶ場合は、サンプルどおり modelId に global.anthropic.claude-opus-5-5 を指定する。IAM に bedrock:InvokeModel と bedrock:InvokeModelWithResponseStream を付与する。
  • 日本の推論プロファイル（jp.）を使いたい場合は、Amazon Bedrock のドキュメントで対応リージョンの一覧を確認する。
  • 生物学・サイバーセキュリティ・AI 開発に関わる処理は、本番で切り替える前に Playground で拒否が増えないか確かめる。

注意点

  • 「タスクあたりの平均コストが下がる」は Anthropic の主張です。自社のワークロードでの実測値ではありません。
  • jp. 接頭辞のモデル ID の完全な文字列は、出典に記載なしです（サンプルは global. のみ）。
