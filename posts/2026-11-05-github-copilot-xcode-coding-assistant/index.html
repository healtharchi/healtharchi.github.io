GitHub Copilot、Xcode内蔵アシスタントに対応

GitHub Copilot が Xcode 標準のコーディングアシスタントから使えるようになりました。Xcode 27.3 beta 以降のパブリックプレビューで全プランが対象。Apple 向けアプリの開発者に関係します。

対象:iOS/macOS アプリ開発者GitHub Copilot 利用者

何が発表されたか

GitHub は、GitHub Copilot を Xcode に組み込まれたコーディングアシスタントの中で直接使えるようにしたと発表しました。提供条件は次のとおりです。

  • 提供段階: パブリックプレビュー（正式版ではありません）
  • 対象バージョン: Xcode 27.3 beta 以降
  • 動作環境: macOS Tahoe 26.6 以降を搭載した Mac
  • 対象プラン: すべての Copilot プラン

既存の GitHub Copilot for Xcode 拡張機能は廃止されず、別の選択肢として残ります。正式版の提供時期と料金は出典に記載なしです。

誰に関係するか

  • iOS/macOS アプリ開発者: Xcode の標準機能として Copilot を使えるようになります。ベータ版の Xcode を試せる環境の人が対象です。
  • GitHub Copilot 利用者: プランを問わず使えます。拡張機能版と標準アシスタント版のどちらで使うかを選べるようになります。
  • 企業のIT部門: プレビューかつベータ版の Xcode が前提のため、業務環境への展開を急ぐ必要は小さいです。
  • 一般利用者: 影響は小さいです。

今日できること

  • 使っている Mac の macOS が Tahoe 26.6 以降かを確認します。条件を満たさない場合は試せません。
  • 試す場合は、Apple Developer Downloads から Xcode 27.3 beta を入手します。業務用の Xcode とは分けて検証するのが無難です（推測）。
  • Xcode のメニューで Xcode > Settings > Intelligence を開き、コーディングアシスタントに GitHub Copilot を設定します。
  • すでに GitHub Copilot for Xcode 拡張機能を使っている場合は、両方を比べて自分に合う方を選びます。気づいた点は GitHub Copilot for Xcode リポジトリか Apple Feedback Assistant で伝えられます。

注意点

  • パブリックプレビューのため、仕様が変わる可能性があります（推測）。
  • 日本からの利用可否、正式版の時期、料金は出典に記載なしです。
