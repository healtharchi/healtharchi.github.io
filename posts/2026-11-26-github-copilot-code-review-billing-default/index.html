GitHub、Copilotレビューの課金既定を組織に変更

GitHubは、Copilot code reviewの課金方法が未選択の組織で、December 30, 2026から課金先を組織に変えます。Copilot BusinessとEnterpriseの管理者は、期限前に設定の確認が必要です。

対象:企業のIT部門GitHubの組織管理者開発チームの予算管理者

判定: 様子見
出典の日付で December 30, 2026 から適用予定の変更で、まだ実施前の発表段階です。日本での扱いは出典に記載がありませんが、Copilot BusinessとEnterpriseの管理者は期限前に課金設定を確かめる必要があります。

何が発表されたか

GitHubは、Copilot code review の課金先の既定値を変えると発表しました。対象は Copilot Business または Copilot Enterprise を使う organization と enterprise です。

変わる点（課金方法が未選択の場合だけ）

  • 今は、有料の Copilot ライセンスを持つメンバーのレビューに、そのメンバーの Copilot entitlement を使います。
  • December 30, 2026からは、リポジトリを所有する organization に課金されます。
  • organization への課金には AI Credits の paid usage が必要で、支出が増える可能性があります。

変わらない点

  • すでに Member か Organization を選んでいれば、その選択が続きます。
  • Copilot ライセンスを持たないメンバー向けの設定は変わりません。

誰に関係するか

  • 企業のIT部門: Copilot Business または Copilot Enterprise を契約し、code review の課金方法をまだ選んでいない場合に関係します。
  • GitHubの organization・enterprise の管理者: 期限までに Member か Organization を選ぶ担当です。enterprise がこの設定を管理している場合は、enterprise owner が選びます。
  • 開発チームの予算管理者: 未選択のまま organization 課金に移ると、organization の支出が増える可能性があります。

今日できること

  • enterprise または organization の Copilot ポリシー設定を開き、code review の課金設定が「Default (Member)」の表示のまま未設定になっていないか確かめます。変更までは、未設定の設定にこの表示と変更の通知が出ます。
  • メンバーの Copilot entitlement を使い続けたい場合は、December 30, 2026より前に Member を選びます。GitHub によると、この選択は既定値が変わった後も有効です。
  • enterprise がこの設定を管理している場合は、enterprise owner に選択を依頼します。
  • 詳しい手順は、GitHub が案内している「Configuring code review by GitHub Copilot」で確認できます。

注意点

  • 今回の変更は、課金方法が未選択の場合だけに当てはまります。
  • 課金の具体的な金額は出典に記載なしです。
  • AI Credits の paid usage が有効でない、billing lock がある、または課金可能な顧客が無いアカウントは、Member に設定されます。
