Sakana AI、Fugu Maxを公開 出力$6/1M

Sakana AI が Fugu Max と Fugu Ultra v2 を OpenAI 互換 API で公開。Fugu Max は入力 $2・出力 $6（1M トークンあたり）。API 費用を比べる開発者向けの内容です。

何が発表されたか

Sakana AI は 2026 年 9 月 11 日、複数のモデルを束ねて使うオーケストレーション基盤 Sakana Fugu の新版を 2 つ公開しました。同じ仕組みを、目的別に調整したものです。

  • Fugu Max: コストを抑える方向の版です。NVIDIA Nemotron ファミリーを含むオープンウェイトモデルや特化型モデルを対象に加え、タスクを解ける最小のモデルへ動的に振り分けます。
  • Fugu Ultra v2: 性能を高める方向の版です。

提供条件は次のとおりです（出典に記載の時点）。

  • どちらも標準の OpenAI 互換 API で、公開日から利用できます
  • 既存の Fugu 利用者は、パラメータを 1 行変えるだけで切り替えられ、移行作業は不要とされています
  • Fugu Max の料金は、1M トークンあたり入力 $2、出力 $6 です
  • Fugu Ultra v2 の料金は出典に記載なし

誰に関係するか

開発者: OpenAI 互換 API を使っている人は、呼び出し先を変える形で試せる選択肢が 1 つ増えました。Sakana AI は、Fugu Max の出力料金が Sonnet 5、GPT 5.6 Terra、Kimi K3 より 40〜60% 低いと説明しています。比較相手の単価は出典に数値がないため、自分で確認が必要です。

AI API の費用を管理する担当者: 同社は、Fugu Max が上位モデルに迫る性能を 2〜6 倍低いコストで出すとしています。ただし「どのタスクで、どのモデルと比べて」かは同社のベンチマークに基づく主張で、本出典には第三者による検証結果は示されていません。

企業のIT部門: 同社によると、Fugu Ultra v2 のモデルプールには Fable 5、Fable 5.1、GPT-6-Astra が含まれていません。特定の大手モデルに依存しない構成を検討している場合の材料になります。

今日できること

  • いま使っているモデルの入力・出力単価を料金ページで確認し、Fugu Max（入力 $2・出力 $6 / 1M トークン）と並べて表にする
  • OpenAI 互換 API のクライアントで接続先を Fugu に変え、自社の代表的なタスクを数件流して、結果の品質と請求額を記録する
  • 既存の Fugu 利用者は、パラメータを 1 行変えて Max と Ultra v2 をそれぞれ試し、自社のタスクで差を確かめる
  • Fugu Ultra v2 を使う場合は、料金が出典に記載されていないため、Sakana AI のコンソールで単価を確認してから切り替える

注意点

  • ベンチマークの数値はすべて Sakana AI の発表によるものです。たとえば Chartography では、Fugu Ultra v2 が 48.3、Opus 5 が 27.3、Fable 5 が 29.5 とされています。社内ベンチマーク（SWEFish）も含まれます。
  • Fugu Max と Fugu Ultra v2 の正確なモデル ID、提供地域、日本からの利用可否は出典に記載なし。
  • Fugu Ultra v2 の学習データのカットオフは 20260828 と記載されています。
