Ollama v0.40.4、判定用モデルをCLIで直接実行

Ollama v0.40.4 で、判定用モデルを ollama run から直接使えるようになりました。はい／いいえの判定やラベル分類をターミナルで試したい開発者と、ollama launch codex の利用者に関係します。

何が発表されたか

Ollama が GitHub で v0.40.4 を公開しました。Latest（最新）リリースとして表示されています。リリースページの日付表示は「12 Oct」で、年の記載はありません。

目玉は「判定用モデル（decision models）」を、ターミナルの ollama run から直接使えるようになった点です。できることは次の3つと書かれています。

  • はい／いいえで答える質問
  • 文章をラベルに分類する
  • ルーブリック（採点基準）に沿って採点する

あわせて、次の変更も入っています。

  • Kev の判定用モデルが、Apple silicon の MLX runner で動くようになった
  • ollama launch が、有料プランに上げなくても usage credits で使えるようになった（金額は出典に記載なし）
  • ollama launch codex のモデル選択に、ローカルにインストールした Ollama モデルが出るようになった
  • llama-server 経由でマルチモーダル埋め込みに対応した
  • MLX runner で、NVIDIA GPU 上の Gemma 4 の prefill 性能が改善された
  • README とドキュメントで、プライバシーとクラウドサービスに関する書き方が明確になった

誰に関係するか

  • 開発者: 問い合わせ文の仕分けなど、はい／いいえで済む判定をコマンド1行で試せます。ollama launch codex を使う人は、ローカルのモデルに切り替えやすくなります。
  • ローカルLLMの利用者: Apple silicon で Kev の判定用モデルを使う人、NVIDIA GPU で Gemma 4 を MLX runner で動かす人に関係します。
  • 一般利用者: Ollama を使っていなければ影響は小さいです。
  • 日本での提供条件: 出典に地域の記載はありません。

今日できること

  • Ollama を v0.40.4 に更新する。
  • リリースノートの例にならい、判定したい文章をファイルに入れて、次の形で試す。例では「返金を求めているか」を尋ねています。
    • ollama run nimble --ask "Is a refund being requested?" < ticket.txt
  • ollama launch codex を使っている場合は、Codex CLI 内で /model を開き、ローカルの Ollama モデルが選べるか確かめる。
  • 有料プランでない場合は、ollama launch が usage credits で使えるか確認する。

注意点

  • 例に出てくる nimble がどの提供元のモデルかは、出典に記載がありません。
  • usage credits の金額や上限は、出典に記載がありません。
