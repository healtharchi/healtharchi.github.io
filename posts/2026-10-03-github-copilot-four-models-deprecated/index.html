GitHub Copilot、4モデルを10月2日に廃止

GitHubは10月2日、Gemini 3.5 Flash・Gemini 3.6 Flash・Kimi K2.7 Code・Claude Opus 4.7をCopilotの全機能で廃止。代替への切り替え手順と管理者の確認点を整理します。

対象:開発者Copilot Enterprise の管理者開発チームのリーダー

判定: 試す価値あり

何が発表されたか

GitHubは2026年10月2日、GitHub Copilotで4つのモデルの提供を終了（廃止）したと公表しました。対象は、Copilot Chat、インライン編集、askモードとagentモード、コード補完を含む、Copilotのすべての機能です。

廃止されたモデルと、GitHubが示した代替は次のとおりです。

廃止されたモデル 示された代替
Gemini 3.5 Flash Gemini 3.8 Flash
Gemini 3.6 Flash Gemini 3.8 Flash
Kimi K2.7 Code Kimi K3
Claude Opus 4.7 Claude Opus 5.5

廃止日は4モデルとも2026年10月2日で、公表と同じ日です。事前の予告期間や移行の猶予は出典に記載がありません。廃止モデルを取り除くための操作は不要ですが、ワークフローや連携で該当モデルを指定している場合は、対応しているモデルに更新するよう求めています。廃止の理由も出典に記載はありません。

誰に関係するか

  • 開発者: 上記4モデルをCopilot Chat、エージェント、コード補完で選んでいた人に直接関係します。これらはCopilotの全機能で使えなくなっています。
  • Copilot Enterprise の管理者: 代替モデルがモデルポリシーで無効のままだと、利用者はモデルセレクターでそのモデルを選べません。ポリシーの確認が必要です。
  • 開発チームのリーダー: スクリプトやCI、社内ツールなどの連携で特定のモデル名を指定している場合、更新の段取りが必要です。
  • 上記4モデルを使っていない利用者: 影響は小さいです。

今日できること

  • ワークフロー、スクリプト、連携設定でモデル名を指定している箇所を探し、Gemini 3.5 FlashとGemini 3.6 FlashはGemini 3.8 Flash、Kimi K2.7 CodeはKimi K3、Claude Opus 4.7はClaude Opus 5.5に置き換える。
  • Copilot Enterprise の管理者は、Copilot settings のモデルポリシーで代替モデルへのアクセスを有効にする。有効にすると、VS Codeとgithub.comのCopilot Chatのモデルセレクターにそのモデルが表示されます。
  • 管理者は、自分のCopilot settingsを開いて、対象モデルのポリシーが有効になっているかを確かめる。
  • GitHub Enterprise を使っていて不明点があれば、担当のアカウントマネージャーに問い合わせる。

注意点

  • 代替モデルの料金や、プランごとの利用条件は出典に記載がありません。
  • 日本での提供条件や、今後ほかのモデルが廃止される予定も出典に記載がありません。
  • 廃止されたモデルを取り除くための操作は不要です。
