GitHub Copilot、Opus 4.8などの廃止を実施

GitHubは2026年11月16日、Claude Opus 4.8・Claude Opus 5・GPT-5.6 TerraをCopilotの大半の機能で廃止しました。モデル名を指定した連携を持つ開発者と管理者に関係します。

何が発表されたか

GitHubは2026年11月16日、GitHub Copilotで次のモデルを廃止したと公表しました。対象はCopilot Chat、inline edits、ask/agentモード、コード補完を含む大半の機能です。廃止は事前に予告されていました（出典の表記では October 15, 2026）。

廃止されたモデル 示された代替
Claude Opus 4.8 Claude Opus 5.5
Claude Opus 5 Claude Opus 5.5
GPT-5.6 Terra GPT-6.1 Sol または GPT-6 Luna

例外として、Claude Opus 4.8は年額プランの個人契約者に引き続き提供されます。Claude Opus 5は選択欄から消えましたが、既存の認可済みアクセスによる runtime refusal fallback の用途では残ります。

誰に関係するか

  • 開発者: ワークフローや連携で、廃止されたモデル名を指定している人です。GitHubはサポートされているモデルへの更新を求めています。
  • 企業のIT部門: 社内のスクリプトや連携ツールで特定のモデル名を固定している場合、更新の段取りが必要です。
  • GitHub Copilot の管理者: Copilot Business・Enterpriseでグローバル既定をオフにしている、またはモデルを個別に無効にしている場合、代替モデルは自動では有効になりません。

今日できること

  • 連携やスクリプトのモデル指定を確認し、Claude Opus 4.8とClaude Opus 5はClaude Opus 5.5へ、GPT-5.6 TerraはGPT-6.1 SolかGPT-6 Lunaへ書き換える。
  • Business・Enterpriseの管理者でグローバル既定をオフにしている場合は、Copilot settings のモデルポリシーで代替モデルへのアクセスを有効にする。
  • 有効化のあと、Copilot Chat のモデル選択欄に代替モデルが表示されるかを確かめる。廃止モデルを取り除く操作は不要です。

注意点

  • 代替モデルの自動有効化は、Copilot Business・Enterpriseで既定のモデル有効化設定を使っている場合に限られます。
  • 既存の enterprise のモデルポリシーは引き続き適用されます。
  • 今回の発表は、GitHubが事前に予告していた廃止の実施を報告するものです。
  • 代替モデルの料金や利用上限、日本での提供条件は出典に記載なしです。
