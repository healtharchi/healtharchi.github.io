Ollama、Liquid AIのLFM3とd1 2Bを追加

Ollama v0.40.12 で Liquid AI の小型モデル群 LFM3 と 2B の d1 決定モデルが追加。lfm3 と d1 2b はこの版では Apple ハードウェアのみ対応。ローカル LLM の開発者向け。

何が発表されたか

Ollama は 2026年10月27日に v0.40.12 を公開しました。目玉は Liquid AI の新しい小型モデル群 LFM3 の追加です。LFM3 はローカルで動くエージェント、ツール呼び出し、構造化出力を目的に作られ、Liquid AI の新しい tri-hybrid architecture に基づきます。

  • lfm3: 1.7B のテキストモデル。コンテキストウィンドウは 256K トークンです。
  • lfm3-vl: 画像理解を追加。lfm3-audio: 18 言語の音声認識・翻訳・読み上げ。lfm3-omni: テキスト・画像・音声を 1 つのモデルで扱います。
  • d1 2B: LFM3 を土台にした決定モデル。テキストと画像について判断し、d1-omni は音声にも対応します。

この版では lfm3 と d1 2b は Apple ハードウェアのみ対応で、Linux/Windows は近日予定です。あわせて、Apple silicon での Gemma 4・Flint・Laguna のプロンプト処理高速化、MLX の speculative decoding の DFlash2 ドラフトモデル対応、ollama launch の OpenCode v2 対応、Kimi CLI 関連の修正と MLX・llama.cpp の更新が入りました。

誰に関係するか

  • ローカルで LLM を動かす開発者: ツール呼び出しや構造化出力を前提にした小型モデルが Ollama から使えます。画像・音声まで同じ系列で揃う点が特徴です。Gemma 4 は小さい画像でも細部を保持するようになりました。
  • Mac で小型モデルを試したい利用者: 新モデルのうち lfm3 と d1 2b は、この版では Apple ハードウェアのみ対応です。Apple silicon でのプロンプト処理の高速化も今回の対象です。
  • Linux/Windows の利用者: lfm3 と d1 2b は今回は使えません。出典は近日対応予定としています。

今日できること

  • Apple ハードウェアなら、v0.40.12 で ollama run lfm3 を実行して LFM3 を試す。
  • テキストや画像の判定用途なら、ollama run d1:2b "対象の文" --ask "質問" の形で d1 を試す。出典の例は、二重請求の問い合わせ文に「これは請求の問題か」と尋ねるものです。
  • 画像や音声を扱うなら、lfm3-vl、lfm3-audio、lfm3-omni のどれが用途に合うかを確認する。
  • OpenCode v2 を使っているなら、ollama launch が動くようになったので試す。

注意点

  • lfm3 と d1 2b の Apple 限定は「この版では」という条件付きです。Linux/Windows は近日対応予定ですが、具体的な対応日は出典に記載がありません。
  • 各モデルのライセンス、性能の数値、必要なメモリ量は出典に記載がありません。導入前に各モデルの配布元で確認が必要です。
