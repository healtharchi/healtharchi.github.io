Copilot、GPT-6.2 AstraとSolを一般提供

GitHub Copilot で OpenAI の GPT-6.2 Astra と Sol が一般提供になりました。対象は Pro+・Max・Business・Enterprise で従量課金です。管理者は自動有効の設定を確認しましょう。

何が発表されたか

GitHub は 2026-11-17、OpenAI の GPT-6.2 Astra と GPT-6.2 Sol を Copilot で一般提供（GA）にしました。どちらもエージェント型コーディングとコードレビュー向けです。

  • GPT-6.2 Astra: エージェント型コーディングとターミナル作業向け。初期テストで GPT-6 Astra より多くの問題を見つけ、トークンも少なかったとされます。
  • GPT-6.2 Sol: 複雑なエージェント型コーディングと詳細なレビュー向け。初期テストで “nearly twice as many real issues in code review as GPT-6.1 Sol” とされます。
  • 対象: Copilot Pro+、Max、Business、Enterprise。提供は段階的です。
  • 料金: 従量課金（提供元の定価）。単価は出典に記載なし。

誰に関係するか

  • 開発者: Copilot Pro+・Max・Business・Enterprise を使っていれば、コードレビューやエージェント作業のモデルを選び直す材料になります。
  • 企業のIT部門: Business・Enterprise では、全体の既定をオフにするか個別に無効化しない限り、新モデルは自動で有効になります。従量課金の費用管理とあわせて、許可するかを決める必要があります。

今日できること

  • Visual Studio Code、Copilot CLI、JetBrains IDEs などのモデルピッカーを開き、GPT-6.2 Astra と GPT-6.2 Sol が表示されるか確認する。段階的な提供のため、無ければ時間をおいて再確認する
  • 用途で使い分けを試す。レビューを深くしたい時は GPT-6.2 Sol、ターミナル作業を含む実装は GPT-6.2 Astra を選ぶ
  • Business・Enterprise の管理者は、Copilot 設定のモデルポリシーで GPT-6.2 モデルを許可するか無効にするかを決める。既定のモデル有効化では、管理者が全体の既定をオフにするか、当該モデルを個別に無効化していない限り、自動で有効になる点に注意する
  • 費用は「Models and pricing for GitHub Copilot」で確認する（出典が案内している参照先）

注意点

  • 料金は従量課金で、具体的な単価はこの出典に記載がありません。
  • 日本での提供可否は出典に記載なしです。
