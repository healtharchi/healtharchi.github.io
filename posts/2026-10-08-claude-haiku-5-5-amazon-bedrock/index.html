AWS、Claude Haiku 5.5を提供開始 日本も利用可

AWSが Claude Haiku 5.5 を Amazon Bedrock で提供開始。JP を含む推論プロファイルで当日から使え、多くのタスクで Haiku 4.5 より約75%安いとしています。

対象:開発者企業のIT部門事業責任者

◎
判定: 今すぐ使う
Amazon Bedrock で当日から利用可能で、JP Geo CRIS (jp.) を含む推論プロファイルが明記されています。AWS は多くのタスクで Haiku 4.5 より約75%安いとしており、AWS 上で生成AIを使う開発者と企業のコスト判断に直接関わります。ただし Claude Platform on AWS は北米のみ、単価は出典に記載なし。

何が発表されたか

AWS は 2026年10月7日、Anthropic の Claude Haiku 5.5 を Amazon Bedrock と Claude Platform on AWS で提供開始したと発表しました。

  • 位置づけ: Anthropic によれば Claude 5.5 ファミリーで最速・最も効率的なモデル。サブエージェントや、大量でコストに敏感な作業向けです
  • コスト: 多くのタスクで Claude Haiku 4.5 より約75パーセント安い、と AWS は記載しています。単価は出典に記載なし（Amazon Bedrock pricing を参照と案内）
  • 新要素: Haiku として初めて effort controls を備え、タスクごとにコストと知能のバランスを調整できます
  • 提供範囲: Amazon Bedrock では US・EU・AU・JP の各 Geo CRIS と Global CRIS の推論プロファイルで当日から利用可。AWS GovCloud (US) でも利用可。Claude Platform on AWS は北米で提供

AWS は、計画と判断を Claude Opus 5.5 に任せ、明確に定義された作業を Haiku 5.5 に大量に回す組み合わせを勧めています。

誰に関係するか

  • 開発者: AWS 上で Claude を使っているなら、サブエージェントや分類・要約などの定型処理の置き換え候補になります。モデルIDの差し替えで試せます。
  • 企業のIT部門: Bedrock 経由なら IAM・CloudTrail・CloudWatch・Bedrock Guardrails をそのまま使え、利用料は AWS の請求に載ります。日本向けには JP Geo CRIS (jp.) が用意されています。
  • 事業責任者: 約75パーセント安いという数値は AWS の記載で、対象は「多くのタスク」です。自社の処理で実測してから判断する材料になります。
  • 一般利用者: 直接の影響は小さいです。

今日できること

  • Amazon Bedrock コンソールで Test → Playground を開き、Haiku 5.5 を選んでプロンプトを試す
  • 既存コードのモデルIDを global.anthropic.claude-haiku-5-5（または jp. などの Geo CRIS プロファイル）に差し替えて動作を確認する
  • 応答でテキストブロックの前に thinking ブロックが返る場合があるため、固定の添字ではなく type でテキストブロックを選ぶように実装を見直す
  • Amazon Bedrock pricing で単価を確認し、Opus 5.5（計画・判断）と Haiku 5.5（大量の定型作業）の役割分担を検討する

注意点

  • Claude Platform on AWS での提供は北米です。日本からの利用条件は出典に記載なし。
  • 「最速・最も効率的」は Anthropic による説明として AWS が紹介しています。「約75パーセント安い」は多くのタスクを対象とした AWS の記載です。これらの測定条件は出典本文に記載されていません。
  • サンプルの前提条件として Python 3.10+、boto3、anthropic、aws_bedrock_token_generator と、IAM 権限 bedrock:InvokeModel / bedrock:InvokeModelWithResponseStream が挙げられています。
  • 対応リージョンの全一覧は Amazon Bedrock ドキュメントを参照するよう案内されています。
