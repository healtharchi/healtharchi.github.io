OpenAI、Agents APIをベータ公開 追加料金なし

OpenAIがCodexと同じ基盤で動くAgents APIをpublic betaで公開。API自体の追加料金はなく、トークンとツールの従量課金のみ。自前でエージェント基盤を運用する開発者の移行判断に関係します。

対象:開発者企業のIT部門

判定: 様子見
全開発者向けに公開済みですが、提供段階は public beta（GA 前）です。日本での提供条件とトークン・ツールの単価も出典に記載がないため「様子見」としました。

何が発表されたか

OpenAI は 2026年9月10日、クラウドで動く AI エージェントを API で作れる「Agents API」を公開しました。全開発者向けの public beta（公開ベータ版）です。Codex と同じハーネス（コンテキストやツール、サブエージェントを調整する部分）を使い、運用は OpenAI が担います。

  • 作り方: タスク・モデル・ツール・実行環境を指定し、1 回の API 呼び出しで作成します（公式例のモデルは gpt-6-astra）。
  • 実行環境: OpenAI 管理のサンドボックス（コード実行やファイル操作の環境）、自社インフラ、Cloudflare や Vercel などパートナーの環境から選べます。
  • 主な機能: コンテキストの自動圧縮、必要なツール定義だけを読む Tool search、サブエージェントによる並列処理。
  • 料金: API 自体の追加料金はなく、使ったトークンとツールの分だけ支払います。

誰に関係するか

  • 開発者: エージェントを自作している人。コンテキストの圧縮やサブエージェントの管理を、自前で書かずに API 側へ任せられます。
  • エージェント基盤を自前で運用しているチーム: 移行するかどうかの判断材料になります。比較の軸は「API の追加料金なし・トークンとツールの従量課金」と、実行環境を自社インフラにも置ける点です。
  • 企業のIT部門: 実行環境を OpenAI 管理・自社インフラ・パートナーから選べるため、データの置き場所の方針に合わせて検討できます。
  • 一般利用者: 影響は小さいです（開発者向けの API です）。

今日できること

  • OpenAI の Agents API の overview と quickstart を開き、使えるツールを確認する。対応は MCP、カスタム関数、Web 検索などの組み込みツールです。
  • 実行環境の 3 つの選択肢（OpenAI hosted sandbox、自社インフラ、パートナーのサンドボックス）のうち、自社の方針で使えるものを決める。
  • OpenAI の料金ページで、エージェントが使うトークンとツールの単価を確認する（今回の出典には単価の記載なし）。
  • 自前のエージェント基盤がある場合は、今の運用費と「追加料金なし・トークンとツールの従量課金のみ」を並べた比較表を作る。

注意点

  • 提供段階は public beta です。GA（一般提供）を目指すとしていますが、時期は出典に記載なし。
  • 日本からの利用可否や地域制限は出典に記載なし。
  • トークンとツールの具体的な単価は出典に記載なし。
  • 顧客の SafetyKit は、案件レビューを Agents API に移して 1 件あたりのコストが 60% 減ったと述べています。これは顧客の主張で、OpenAI の保証ではありません。
  • 以上は出典（2026年9月10日公開）に記載の時点の情報です。
