何が発表されたか

OpenAI は 2026年9月29日、GPT-6 Sol の後継 GPT-6.1 Sol を公開しました。GPT-6 Astra に近い能力を、Astra の標準入出力トークン価格の 5 分の 1 で提供する位置づけです。

API の標準価格（出典に記載の時点、1M トークンあたり）は入力 $2、キャッシュ入力 $0.10、出力 $10。キャッシュ入力は標準入力より 95% 安く、GPT-6 Sol のキャッシュ入力より 50% 安いと説明しています。

提供先は API と、ChatGPT Work・Codex（Plus・Pro・Business・Enterprise・Edu に当日から）で、Chat では未提供です。また数日中に GPT-6.1 Sol Ultrafast を提供予定で、Codex での標準速度と比べトークン生成が最大 8 倍速いと説明しています。

誰に関係するか

  • 開発者（OpenAI API 利用者）: GPT-6 Sol から gpt-6.1-sol への切り替え候補です。同じコンテキストを繰り返し送るエージェント用途では、キャッシュ入力 $0.10 の効果が大きくなります。
  • Codex・ChatGPT Work の利用者: 対象プランなら当日から選べます。Chat では未提供なので、Chat 中心の使い方には今回は変化がありません。
  • 企業の IT 部門・費用管理の担当者: Astra を使っている処理のうち、Sol 系で足りるものを切り分ける判断材料になります。ただし Astra や GPT-6 Sol の価格自体はこの発表に記載なしで、「5 分の 1」「50% 安い」は相対表現です。
  • 一般利用者: Chat には未提供のため、今日の時点で影響は小さいです。
