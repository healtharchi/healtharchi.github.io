GitHub Copilot、3モデルを11月16日に廃止

GitHubはCopilotでClaude Opus 4.8・Claude Opus 5・GPT-5.6 Terraを2026年11月16日に廃止します。指定中のワークフローは期日までに代替モデルへ切り替えが必要です。

対象:開発者企業のIT部門

○
判定: 試す価値あり
対象モデルを指定している利用者は、2026年11月16日の廃止前にワークフローと連携をサポート対象モデルへ更新する必要があるため、移行準備を進める判定です。対象はこの3モデルの利用者に限られ、年額プランの個人向けCopilot契約者が使うClaude Opus 4.8は廃止対象外です。

何が発表されたか

GitHub は2026年10月15日、GitHub Copilot で使える3つのモデルを廃止すると発表しました。廃止日はいずれも2026年11月16日です。

対象は Copilot Chat、インライン編集、ask モードと agent モード、コード補完を含む、Copilot のすべての利用場面です。

廃止されるモデル 廃止日 GitHub が示す代替
Claude Opus 4.8 2026-11-16 Claude Opus 5.5
Claude Opus 5 2026-11-16 Claude Opus 5.5
GPT-5.6 Terra 2026-11-16 GPT-6.1 Sol または GPT-6 Luna

例外が1つあります。年額プランの個人向け Copilot 契約者には、Claude Opus 4.8 が引き続き提供されます。この契約者には Opus 4.8 の廃止は適用されません。

GitHub は、期日までにワークフローと連携をサポート対象のモデルへ更新するよう求めています。日本での提供条件は出典に記載なしです。

誰に関係するか

  • 開発者: 3モデルのいずれかを指定してワークフローや連携を組んでいる人は、11月16日までに切り替えが必要です。年額プランの個人契約で Claude Opus 4.8 を使っている場合は、このモデルについては影響を受けません。
  • 企業のIT部門（Copilot 管理者）: Copilot Enterprise と Copilot Business では、既定のモデル有効化設定のままなら代替モデルが自動で有効になります。グローバル既定をオフにしている、または代替モデルを明示的に無効にしている組織は、自動では有効になりません。
  • 一般利用者: Copilot を使っていなければ影響は小さいです。

今日できること

  • 社内のワークフローや連携で、Claude Opus 4.8・Claude Opus 5・GPT-5.6 Terra を指定している箇所を洗い出す。
  • 見つかった箇所を、2026-11-16 までに代替モデル（Claude Opus 5.5、GPT-6.1 Sol、GPT-6 Luna）へ切り替える。年額プランの個人契約者が使う Claude Opus 4.8 は対象外です。
  • Copilot Enterprise / Business の管理者でグローバル既定をオフにしている場合は、Copilot settings のモデルポリシーで代替モデルを有効にする。
  • 有効化のあと、Copilot Chat のモデル選択欄に代替モデルが表示されるか確認する。

注意点

  • 代替モデルの自動有効化は、Copilot Enterprise と Copilot Business で既定のモデル有効化設定を使っている場合に限られます。
  • 質問や懸念がある GitHub Enterprise の顧客には、担当のアカウントチームへの連絡が勧められています。
  • 廃止後にモデルを取り除くための操作は不要とされています。
  • 代替モデルの料金や利用上限は出典に記載なしです。
