GitHub Copilot、予算追加申請を一般提供

Copilot の AI credits を使い切ったメンバーが予算追加を申請し、管理者が設定画面で承認できる機能が一般提供に。対象は usage-based billing の Business と Enterprise です。

対象:企業のIT部門Copilot の請求を管理する担当者開発者

一般提供済みですが、対象は usage-based billing の Copilot Business と Copilot Enterprise に限られます。日本から使えるかは出典に記載がないため、自社の契約で表示されるかを確かめてから運用に組み込む段階です。

何が発表されたか

GitHub は 2026 年 9 月 16 日の Changelog で、Copilot の「予算追加の申請」機能を一般提供（GA）にしたと発表しました。

これまで: メンバーが自分に割り当てられた Copilot AI credits（Copilot の利用量に応じて消費される枠）を使い切ると、credits を消費する Copilot 機能が使えなくなっていました。

今回から: 上限に達したその時点で、メンバー本人が予算の追加を申請できます。流れは次のとおりです。

  • 申請は、その予算を支払っているアカウントに自動で届きます。組織が持つ予算なら組織の設定、Enterprise が持つ予算なら Enterprise の設定に表示されます。
  • organization owner、enterprise owner、billing manager が「Requests from members」で保留中の申請を確認します。
  • 申請ごとに新しい金額を決めて「Approve and increase」を選ぶと、予算がその金額に更新され、AI credits がすぐ使える状態に戻ります。
  • 管理者は設定画面の中で、承認・金額の調整・却下のいずれかを選べます。

対象は、usage-based billing（使った分だけ課金される方式）の GitHub Copilot Business と GitHub Copilot Enterprise です。

誰に関係するか

Copilot の請求を管理する担当者: メンバーからの予算追加の依頼を、設定画面の申請一覧で受けて処理できるようになります。承認時に金額を自分で決められるため、申請どおりに増やすかどうかを都度判断できます。

企業のIT部門: 予算を組織と Enterprise のどちらが持っているかで、申請が届く画面が変わります。確認する担当者を決めておく必要があります。

開発者（メンバー）: credits を使い切っても、その場で追加を申請できます。承認されればすぐに使える状態に戻ります。

個人で Copilot を契約している人: 出典で対象として挙げられているのは Business と Enterprise だけで、個人向けプランについては記載がありません。

今日できること

  • 組織または Enterprise の設定で「Requests from members」を開き、保留中の予算追加申請が無いかを確認する。
  • 自社の Copilot 予算が組織と Enterprise のどちらに設定されているかを確かめ、申請を見る担当者（owner または billing manager）を決める。
  • GitHub のドキュメント「Setting up budgets to control spending on metered products」を読み、メンバーごとの予算の初期値を見直す。
  • 申請の扱い方は「Managing requests for additional Copilot budget」で確認する。

注意点

  • 今回は予算追加申請の運用機能の発表です。料金額や credits の単価、料金変更の有無は出典に記載がありません。
  • 承認時に設定できる金額の上限・下限、申請が届いたことの通知方法は、出典に記載がありません。
  • 日本からの利用可否など地域の条件は、出典に記載がありません。
