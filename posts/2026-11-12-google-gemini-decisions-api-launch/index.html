Google、Gemini Decisions APIを提供開始

Googleが判断専用の新エンドポイントGemini Decisions APIを公開しました。入力1Mトークンあたり$0.10で出力は課金なし。振り分けや採点をAIで行う開発者向けで、日本での提供条件は出典に記載がありません。

何が発表されたか

Google は 2026-11-11 付の公式ブログで、新しいエンドポイント Gemini Decisions API を発表しました。使うモデルは新モデル Gemini Decision 1（モデルID: gemini-decision-1）です。Google AI Studio の Gemini API から利用できます。

文章を生成するのではなく、あらかじめ決めた選択肢の中から答えを選ぶ判断に特化しています。

  • 入力: テキスト・画像・音声・動画・PDF をまとめた1つの入力（最大256Kトークン）
  • 質問数: 1回のリクエストで最大1,000件の独立した質問
  • 質問の型: noul（yes/no）、choice（2〜255の選択肢から選ぶ）、score（0から始まる段階評価）の3種類
  • 返り値: 確率と信頼度スコア（0〜1）。判断があいまいなケースを人の確認に回す用途が想定されています
  • 速さ: Google によると end-to-end で 150-250 ms
  • 料金: 入力 1M トークンあたり $0.10、出力トークンは $0。Google AI Studio にはプロトタイピング用の無料枠があります

誰に関係するか

  • 開発者: 問い合わせの振り分け、ツール選択、ポリシーチェックなど、答えの候補が決まっている判断を実装している人に関係します。
  • AIエージェント・アプリの開発チーム: どのモデルに処理を回すかを決める前段の判定に使えます。Google 社内では Gemini Notebook がこの用途で使っていると説明されています。
  • コンテンツ審査・品質管理の担当者: 画像やPDFを基準に照らして採点する仕組みを作る場合に検討対象になります。
  • 一般利用者: 開発者向けの API のため、直接の影響は小さいです。

今日できること

  • API キーを取得して試す: Google AI Studio で API キーを取り、モデル gemini-decision-1 を指定して呼び出します。出典のサンプルコードは api_version に v1beta を指定しています。
  • ドキュメントを読む: Decisions API のドキュメントに Python・JavaScript・REST のガイドがあります。
  • デモアプリを触る: 出典では Doorstep Parcels、Speed Sketch、Find the Zoo Keeper が紹介されています。
  • 置き換え候補を洗い出す: 今は生成型のモデルに yes/no や分類を答えさせている処理があれば、noul・choice・score のどれで表せるかを書き出します。

注意点

  • 料金の数え方: 共通の入力は、質問がいくつあってもリクエストごとに1回だけ課金されます。質問ごとに増えるのは、その質問の指示文と選択肢の説明の分です。
  • 比較の条件: Google は「Interactions API 上の Gemini 3.5 Flash-Lite より約5倍安い」としていますが、これは Google の共通ベンチマークスイートでの比較です。自社のデータでの費用は試算が必要です。
  • 遅延の条件: 遅延がほぼ一定とされるのは、16Kトークンまでの入力で1〜100問の場合です。
  • 提供範囲: Gemini in Google Cloud への対応は今後予定されています。OpenRouter、LangChain、Vercel、LiteLLM などとの連携は順次展開中です。
  • 地域: 日本から利用できるかは出典に記載なし。料金・提供状況は出典発表時点（2026-11-11）の情報です。
