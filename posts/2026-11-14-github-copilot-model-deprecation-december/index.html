GitHub Copilot、一部モデルの廃止を予告

GitHubは、Claude Fable 5やGemini 3.8 Flashなどを December 14, 2026 に GitHub Copilot で廃止すると発表。該当モデルを使う開発者と管理者は、期日までに切り替えが必要です。

何が発表されたか

GitHub は 2026-11-13 の changelog で、GitHub Copilot の一部モデルを December 14, 2026 に廃止（deprecate）すると発表しました。Copilot Chat や code completions を含む、すべての Copilot の体験が対象です。対象と推奨の代替は次のとおりです。

廃止されるモデル 推奨の代替
Claude Fable 5 Claude Fable 5.2
Claude Haiku 4.5 Claude Haiku 5.5
Gemini 3.8 Flash Gemini 4 Hydrogen
Gemini 4 Argon Gemini 4 Carbon
Grok 4.6 Grok 4.7
Kimi K3 To be announced（未発表）

Claude Haiku 4.5 だけは例外で、年額プランの個人契約者には引き続き提供されます。

誰に関係するか

  • 開発者: 上の表のモデルを普段選んでいる人は、期日までに代替へ移る必要があります。
  • Copilot を組み込んだワークフローの運用担当: ワークフローや連携でモデルを指定している場合、GitHub は期日までの更新を求めています。
  • Copilot Business / Enterprise の管理者: default model enablement のもとでは、代替モデルは自動で有効になります。ただし global default をオフにしている組織、またはそのモデルを明示的に無効にしている組織では、自動では有効になりません。
  • 年額プランの個人契約者: Claude Haiku 4.5 に限り、引き続き使えます。
  • Copilot を使っていない人: 影響は小さいです。

今日できること

  • ワークフローや連携の設定を見直し、表の左列のモデルを指定していないか確認する。指定していたら、December 14, 2026 までに対応モデルへ切り替える。
  • 管理者で global default をオフにしている場合は、Copilot settings の model policies を開き、代替モデルへのアクセスを有効にする。
  • GitHub Enterprise の顧客で質問や懸念がある場合は、account team に連絡する。

注意点

  • Kimi K3 の代替は、出典の時点（2026-11-13）では未発表です。
  • 廃止されたモデルを取り除くための操作は不要と、GitHub は説明しています。
  • 廃止の理由は出典に記載なしです。
  • 日本での扱いについて、出典に個別の記載はありません。
  • 日付と対象モデルは出典に記載の時点のものです。
