Anthropic、ライフサイエンス向けLSVP開始

何が発表されたか

Anthropic は 2026 年 9 月 17 日、Life Sciences Verification Program（LSVP）を発表しました。審査を通ったライフサイエンスの専門家に対し、生物学に関わる作業でセーフガード（安全のための制限）を通常より緩めたうえで、Mythos・Opus・Sonnet を使えるようにする仕組みです。

変わるのはモデルの性能ではなく、どこまでの依頼に応じるかという線引きです。

提供はベータで、対象は当初 teams と institutions です。個人の Pro・Max プランへの拡大は今後とされています。早期アクセスで既に数十の組織が参加しており、今回から広く申請を受け付けます。

申請には、研究者としての資格・セキュリティ基準・倫理的な研究監督体制の審査があります。通った teams は 2 種類の枠（grant）を申請できます。

誰に関係するか

ライフサイエンス分野の研究者・企業: 直接の対象です。枠は 2 種類あり、性格がはっきり違います。

  • Standard Use: 日々の幅広い業務向けで、チーム全体に適用できます。更新は年 1 回です。現時点の対象は Mythos 5.1・Opus 5・Sonnet 5 で、今後出るモデルにも適用されるとしています。
  • High-risk Use: Standard Use では止まってしまう領域向けの追加枠です。ライフサイエンスの依頼を止めるセーフガードをすべて解除しますが、その代わり対象はチーム全体ではなく単一の研究プロジェクトに限られ、更新は 6 か月ごとになります。現時点で使えるのは Claude Opus 5 と Claude Sonnet 5 です。Claude Mythos については、追加の審査を受けた少数の組織に限られます。

企業のIT部門: データの扱いが通常と変わる点が要注意です。LSVP では、依頼のたびにその場で止める方式から、後からまとめて確認する方式（オフラインの監視）に切り替わります。そのため LSVP の通信は 30 日間のデータ保持が必須になります。保持されたデータはモデルの学習には使われず、Anthropic のライフサイエンス研究チームからもアクセスできないと説明されています。

Anthropic の API を使う開発者: 枠は Claude Science・Claude.ai・Claude Code・API のすべてで使えますが、切り替えの自由度が異なります。API と Claude Science では枠を切り替えられます。Claude.ai と Claude Code では、当初はあらかじめ選ばれた既定の枠だけが適用されます（API 認証で Claude Code を使う場合を除く）。

ライフサイエンス以外の利用者: 影響は小さいです。緩められるのは生物学に関わる部分だけで、cyber classifiers などその他のセーフガードは LSVP の枠でもそのまま維持されます。

今日できること

  • ライフサイエンスの業務で Claude を使っているなら、Anthropic の発表ページにある申請フォームから LSVP に申請し、必要なのが Standard Use か High-risk Use かを先に決める。
  • 自社が使っている窓口が対象かを確認する。現時点の対象は、API 利用向けの自社 console と、Claude for Enterprise・Claude for Team です。個人向けプランと第三者プラットフォームは未対応です。
  • 30 日間のデータ保持が必須になる点を、社内のデータ取り扱い方針と突き合わせておく。
  • PHI（保護対象の医療情報）を扱っていて BAA を結んでいる組織は、ベータの間は LSVP を使えないため、別組織を用意する必要があるかを確認する。

注意点

  • 料金についての記載は出典にありません。追加費用がかかるかどうかは分かりません。
  • 日本から使えるかどうか、地域ごとの条件も出典に記載がありません。
  • High-risk Use で解除されるのは、ライフサイエンスの依頼を止めるセーフガードに限られます。すべての制限が無くなるわけではありません。
  • 対象モデルの表記は出典どおりです。Standard Use は Mythos 5.1・Opus 5・Sonnet 5、High-risk Use は Claude Opus 5・Claude Sonnet 5 と書かれています。
