Claude Code、auto mode判定が課金対象外に

Claude Code v2.1.278 で、Claude API・Enterprise と Bedrock 等の利用者の auto mode 判定が既定でサーバー側実行になり、判定分の課金が無くなりました。従量課金のチームが対象です。

何が発表されたか

Anthropic が 2026年9月19日 03:10 に、Claude Code の v2.1.278 を公開しました（Latest 表示）。変更は auto mode の判定処理（classifier）の扱いに関するものです。auto mode そのものの機能説明は、今回の出典にはありません。

  • 対象は、Claude API と Enterprise の利用者、および Bedrock・Vertex・Foundry・ゲートウェイ経由の利用者です。
  • これらの環境では、判定を行う classifier が既定でサーバー側で動くようになりました。
  • 出典には、この方式では classifier の処理分を課金しない（does not charge for classifier overhead）と書かれています。
  • 課金が発生する方式に切り替わった場合は、警告が表示されます。
  • /status に「Auto mode server」の行が追加され、そのセッションの classifier がサーバー側で動いているかが分かります。
  • 詳細の案内先として https://code.claude.com/docs/en/auto-mode-classifier-billing が示されています。

金額・単価・削減率は出典に記載なしです。

誰に関係するか

  • 開発者: Claude API 経由で Claude Code を使っている場合、更新するだけで判定分の課金の扱いが変わります。/status で現在の状態を確認できます。
  • 企業のIT部門: Enterprise 契約や、Bedrock・Vertex・Foundry・ゲートウェイ経由で配っている場合が対象です。従来の挙動に戻す設定も用意されています。
  • 定額プランだけで使っている人: 今回の変更は上記の利用形態について書かれたものです。それ以外への影響は出典に記載がありません。

今日できること

  • Claude Code を v2.1.278 に更新し、/status の「Auto mode server」の行で、サーバー側の classifier が使われているかを確認する。
  • Bedrock・Vertex・Foundry・ゲートウェイ経由で従来の挙動に戻したい場合は、環境変数 CLAUDE_CODE_AUTO_MODE_SERVER=0 を設定する。
  • 実行中の表示を見て、課金の伴う方式へのフォールバックの警告が出ていないかを確認する。
  • 課金の詳しい条件は https://code.claude.com/docs/en/auto-mode-classifier-billing を読む。

注意点

  • 課金しないと書かれているのは classifier の処理分だけです。それ以外の課金がどうなるかは、出典に記載がありません。
  • CLAUDE_CODE_AUTO_MODE_SERVER=0 による除外は、Bedrock・Vertex・Foundry・ゲートウェイについてのみ書かれています。
  • 日本から利用できるかどうかについて、出典に地域の記載はありません。
