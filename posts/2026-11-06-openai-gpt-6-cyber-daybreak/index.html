何が発表されたか

OpenAIは2026年11月5日、サイバーセキュリティ用のモデル GPT‑6 Cyber を発表しました。脆弱性を見つけて検証し、修正案を作るためのモデルです。研究者が決めた範囲の外を攻撃しないよう、専用の訓練をしたと説明しています。

前の世代 GPT‑5.6 Cyber との違いは次のとおりです。

  • 攻撃の成功率: ExploitGym（指定した脆弱性を突けるかを測る評価）で 48.5%。GPT‑5.6 Cyber は 32.1% でした。
  • 範囲を守る力: 範囲外のサービスを攻撃しなかった割合は、デプロイ用プロンプトなしで 99.93%（GPT‑5.6 Cyber は 94.49%）、ありで 100% です。
  • 社内の分類: OpenAI の Preparedness Framework で、サイバー分野の Critical に分類されました（GPT‑5.6 Cyber は High）。

実績として、Mozilla が高深刻度と分類した Firefox の未知の脆弱性 81 件を見つけています。Linux カーネルでは 1,724 件を再現し、948 件で動くエクスプロイトを作りました。うち 304 件の重大な発見は、修正案つきでメンテナに開示済みです。

提供は当初、承認済みの一部 Daybreak Red 顧客に限られます。経路は API と Codex で、今後すべての Daybreak Red 顧客へ順次広げる予定です。拡大の時期は出典に記載がありません。

誰に関係するか

  • 企業のセキュリティ部門: 脆弱性調査やコードレビューに使える候補です。ただし Daybreak Red の承認が前提です。
  • 脆弱性診断の実務者: Web アプリの侵入テスト評価では、脆弱性の再現率が 40.3% でした（GPT‑6 Astra は 32.0%）。
  • オープンソースのメンテナ: Firefox や Linux のように、AI が見つけた脆弱性の報告が届く場面が増えそうです（推測）。
  • 一般利用者・多くの開発者: 今回は承認制の限定提供のため、直接の影響は小さいです。

今日できること

  • 申し込み資格を確かめる: Daybreak に申し込み、Daybreak Red と Daybreak Blue のどちらの利用資格があるか確認します。
  • 接続元の IP を整理する: Daybreak Red の API は既定で IP 許可リストが必要です。社内から接続するネットワークを先に洗い出します。
  • 安全な作業環境を用意する: 高リスクの作業では、サンドボックス化・操作の確認・人による監督が推奨されています。
  • 評価の詳細を読む: 各評価の条件と全結果はシステムカードで確認できます。

注意点

  • 料金は出典に記載がありません。
  • 日本での提供可否も出典に記載がありません。
  • Zero Data Retention を使う API 顧客は、原則として Private Safety Processing（PSP）を使う必要があります。暗号化された記録が顧客側のストレージに 30 日保持されます。
  • 重要インフラの防御者向けには、新しい枠 Daybreak Red for Critical Infrastructure が設けられました。
