何が発表されたか

OpenAIは2026-11-06、コーディング用エージェントCodex CLIの新版0.167.0をGitHubで公開しました。主な変更を目的別にまとめます。

  • 作業の見渡し: codex agents --no-daemon でコマンドセンターを開け、未読の結果が示されます。承認画面を開いたままパッチの詳細も展開できます。
  • 企業環境: gcp_setup_wizard を有効にすると、Google Cloud Vertex AIを設定できます。macOSとWindowsでは /experimental からシステムのプロキシ設定を選べます。
  • 修正: モデル提供元を切り替えても、保存済みのチャットが見えるままになりました。

画像添付のプレビューは対応ターミナルのみです。Vertex AIで使えるモデル名は出典に記載なしです。

誰に関係するか

  • 開発者: 複数のエージェント作業を並べて進める人は、コマンドセンターの未読表示で、まだ見ていない結果が分かります。承認の前にパッチの中身も確かめられます。
  • 企業のIT部門: 社内プロキシの内側で使う場合や、Google Cloud経由で使う場合に関係します。app-serverを管理していれば、ネットワーク制約の説明が追加されています。
  • 一般利用者: Codex CLIを使っていなければ、影響は小さいです。

今日できること

  • Codex CLIを0.167.0に更新し、codex agents --no-daemon でコマンドセンターを開いて未読の結果を確認する。
  • Google Cloud Vertex AIで使う場合は、gcp_setup_wizard を有効にし、Application Default Credentialsか認証情報ファイルで設定する。
  • 社内プロキシ環境のmacOSまたはWindowsでは、/experimental からシステムプロキシ設定を試す。実験的な設定なので、まず一部の端末で確かめる。
  • app-serverを管理している場合は、READMEの [permissions.network] の説明を読み、ネットワーク制約を見直す。

注意点

  • システムプロキシ設定は /experimental から選ぶ任意の設定です。
