Ollama、Inkling 2 Mini対応のプレリリース

Ollama が v0.40.17-rc3 をプレリリース公開。Inkling 2 Mini に対応し、Claude Code 連携や Apple silicon での同時処理、GPU の読み込み不具合も改善。ローカル実行の開発者向け。

何が発表されたか

Ollama（手元のパソコンでAIモデルを動かすツール）が、GitHub で v0.40.17-rc3 を公開しました。ページ上の表示は Pre-release で、正式版ではありません。主な変更を目的別にまとめます。

  • 新しいモデルへの対応: Thinking Machines の Inkling 2 Mini を ollama run inkling-2-mini で動かせます。26B パラメータのうちアクティブは 5.4B で、約 20GB で Mac に収まると書かれています。テキストと画像、ツール呼び出し、thinking を扱えます。
  • 性能の記載: SWE-Bench Verified で 79.2% と記載されています。評価の条件は出典に記載なしです。
  • Claude Code との連携: ollama launch claude が Claude Code の deferred tool loading に対応しました。MCP ツールを一度に全部ではなく、必要なときに読み込みます。
  • Mac での動作: Apple silicon 上で、複数のリクエストを同時に処理するようになりました。
  • GPU まわりの修正: Vulkan が統合 GPU で mmap を使うようになり、共有メモリ GPU での Failed to allocate pinned memory による読み込み失敗が修正されました。また、Windows の iGPU で、モデルを部分的にオフロードした場合の KV キャッシュ確保失敗が修正されました。
  • API と設定の細かな変更: ツール定義の JSON schema キーワードが削除されずに残るようになりました。thinking を無効にすると、そのモデルの最も低い推論レベルが使われます。context shift の設定変更でモデルが再読み込みされなくなりました。

誰に関係するか

  • 開発者（ローカル実行）: Inkling 2 Mini を手元で試せます。Vulkan 利用時に共有メモリ GPU で Failed to allocate pinned memory が出ていた人や、Windows の iGPU でモデルを部分的にオフロードした際に KV キャッシュ確保に失敗していた人は、修正内容を確認する対象です。
  • 開発者（Claude Code 併用）: ollama launch claude で MCP ツールの読み込み方が変わります。
  • Apple silicon の Mac 利用者: 複数のリクエストを同時に処理できるようになりました。

今日できること

  • ollama run inkling-2-mini を実行し、手元の Mac で動くか確かめる（約 20GB と記載）。
  • ollama launch claude を使っている場合は、MCP ツールが必要時に読み込まれる挙動に変わる点を確認する。
  • Vulkan 利用時に共有メモリ GPU で Failed to allocate pinned memory が出ていた場合は、このプレリリースで解消するか確かめる。

  • 79.2% はリリースノート上の記載で、評価条件は示されていません。
