Google、Gemini 3.8 Live を提供開始

Google DeepMind が音声モデル Gemini 3.8 Live と Extended Thinking を発表。開発者は Gemini API で当日から、企業向けはプライベートプレビュー。日本での提供可否は記載なし。

何が発表されたか

Google DeepMind は 2026 年 9 月 15 日、音声で対話するための新しいモデル 2 種類を発表しました。「Gemini 3.8 Live」と「Gemini 3.8 Live Extended Thinking」です。

出典によると、この 2 つは狙いが分かれています。

  • Gemini 3.8 Live: 規模とコスト効率を目的に作られたモデルです。
  • Gemini 3.8 Live Extended Thinking: 複雑度の高い作業向けに、多段階の推論を強めたモデルです。

どちらも発表当日から提供が始まります。開発者向けは Gemini API と Google AI Studio、企業向けは Gemini Enterprise でのプライベートプレビュー（限られた利用者だけが試せる段階）です。Gemini Enterprise for Customer Experience については、今後提供する予定とされていますが、具体的な日付は示されていません。

誰に関係するか

開発者: Gemini API と Google AI Studio で当日から使えます。Gemini 3.8 Live は会話の途中で 97 の対応言語を自動で検知し、切り替えると説明されています。また、会話を続けたまま裏でツールや API 呼び出しを実行できるとされています。

企業のIT部門: 企業向けはプライベートプレビューの段階です。Gemini Enterprise for Customer Experience は近日提供予定と書かれているだけで、時期は示されていません。今は導入計画を立てる段階ではなく、対象になるかを確かめる段階です。

Google Workspace の利用者: 3.8 Live Extended Thinking を使える範囲が契約プランで変わります。個人向けでは、Docs は Google AI Pro / Ultra の契約者、Gmail と Keep はすべての Google AI 契約者が対象です。なお、Google Workspace の法人顧客向けは近日提供予定とされ、具体的な提供日は記載されていません。

一般利用者: 3.8 Live は Search Live、3.8 Live Extended Thinking は Gemini Live で提供されます。

音声インターフェースの開発基盤を使っている事業者: Gemini Live API を通じて、Agora、Fishjam、LangChain、LiveKit、Pipecat、Vercel、Vision Agents といったプラットフォームが対応していると記載されています。

今日できること

  • Gemini API または Google AI Studio を開き、Gemini 3.8 Live と Gemini 3.8 Live Extended Thinking が自分のアカウントで使えるかを確認する。
  • 自社の Google Workspace の契約プランを確認する。個人向けでは Docs が Google AI Pro / Ultra、Gmail と Keep がすべての Google AI 契約を条件としています。法人顧客向けは近日提供予定とされているため、現時点で提供日を前提にした計画は立てられません。
  • 企業導入を検討している場合は、Gemini Enterprise のプライベートプレビューの対象になるかを確認する。
  • LiveKit や Pipecat などで音声機能を作っている場合、Gemini Live API 経由で新モデルを使えるかを確認する。

注意点

  • 料金は分かりません。出典にあるのは「コスト効率が高い」「競争力のある価格」という表現だけで、単価も課金単位も書かれていません。費用の比較は今のところできません。
  • 性能の数値は Google 自身の発表です。Google は 3.8 Live Extended Thinking について、Artificial Analysis の Speech to Speech Quality Index で 82.6 の 1 位、τ-Voice で 68.6%、Sierra の τ-Voice-banking で 35.1%、Big Bench Audio で 97.7% としています。Gemini 3.8 Live は Speech Agent Arena で 2 位としています。ここで紹介した数値は、いずれも Google の発表に記載されたものです。
  • 日本から使えるかは出典に記載がありません。提供時期についても書かれていません。
  • Google の AI 製品が生成した音声には、AI 生成と判別できるよう SynthID の電子透かしが埋め込まれると記載されています。
