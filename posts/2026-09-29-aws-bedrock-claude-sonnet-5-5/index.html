Claude Sonnet 5.5がBedrockで利用可能に

AWSがClaude Sonnet 5.5をBedrockとClaude Platform on AWSで提供開始。BedrockはGlobal CRIS経由で当日から使え、大半の作業でOpus 5.5より低コストとAWSは説明。

対象:開発者企業のIT部門AI API の費用管理担当者

何が発表されたか

AWS は 2026年9月28日、Anthropic の Claude Sonnet 5.5 を Amazon Bedrock と Claude Platform on AWS で提供開始したと発表しました。AWS は先に Claude Opus 5.5 の提供開始も発表しており、Sonnet 5.5 はそれと組み合わせて使う位置づけです。

提供条件（出典に記載の時点）:

提供経路 条件
Amazon Bedrock（bedrock-runtime） Global CRIS（global.）の推論プロファイル経由で当日から利用可能
Claude Platform on AWS 北米

AWS による使い分けの説明（いずれも AWS の主張です）:

  • Sonnet 5.5: 進め方が決まっていて、あとは素早く実行すればよい作業向け。大半の作業で Opus 5.5 よりタスクあたりのコストが低く、より高速としています。継続的に、または大量に動かす処理に向くとしています。
  • Opus 5.5: 判断を要する作業向け。リリース時のデバッグ、複数の PR にまたがる機能開発、大規模な PR のセキュリティレビュー、目標が明確なコード移行などを挙げています。

具体的な単価はこの発表に記載がなく、Amazon Bedrock pricing を参照するよう案内されています。対応リージョンの一覧も Amazon Bedrock のドキュメント参照です。

呼び出し方:

  • Anthropic SDK から Anthropic Messages API（bedrock-runtime 向け）で呼ぶ
  • AWS CLI／AWS SDK から Invoke API・Converse API で呼ぶ
  • 応答は text ブロックの前に thinking ブロックが付くことがあります。固定の位置ではなく、種類で text ブロックを選ぶ必要があります。

誰に関係するか

  • 開発者（Bedrock で Claude を使っている人）: モデル ID の切り替えを検討する対象です。コード例のモデル ID は global.anthropic.claude-sonnet-5-5 です。Messages API と Invoke／Converse API のどちらからも呼べます。
  • 企業のIT部門: Bedrock ではリージョン単位のデータレジデンシーでデータが AWS 基盤内にとどまり、IAM・CloudTrail・CloudWatch・Bedrock Guardrails と連携します。利用料は AWS の請求にまとまります。Claude Platform on AWS は北米で利用可能と記載されています。
  • 費用管理の担当者: 「大半の作業で Opus 5.5 よりタスクあたりのコストが低い」は AWS の説明で、金額は出典に記載なしです。見積もりは Amazon Bedrock pricing での確認が必要です。
  • 一般利用者: Bedrock 経由の開発者向け提供なので、直接の影響は小さいです。

今日できること

  • Amazon Bedrock コンソールで Test → Playground を開き、Sonnet 5.5 を選んで、いま使っているプロンプトを試す。
  • API から呼ぶ場合は、コード例どおり modelId に global.anthropic.claude-sonnet-5-5 を指定し、応答は type が text のブロックを選んで取り出す。
  • IAM に bedrock:InvokeModel と bedrock:InvokeModelWithResponseStream を付与する。コード例の前提は Python 3.10+ と Boto3 です。
  • Amazon Bedrock pricing で単価を、Amazon Bedrock のドキュメントで対応リージョンを確認し、判断が必要な作業は Opus 5.5、進め方が決まった作業は Sonnet 5.5 という分担を検討する。

注意点

  • 「タスクあたりのコストが低い」「高速」は AWS の説明で、自社ワークロードでの実測ではありません。
  • Bedrock の提供経路は Global CRIS（global.）と記載され、コード例のリージョンは us-east-1 です。日本リージョンへの対応は、この発表では確認できません。
