GitHub Copilot、GPT-5.5など旧モデルを廃止

GitHubは2026年10月19日、CopilotからGPT-5.5、Gemini 3.7 Flash、Grok 4.5などを廃止しました。指定している連携の切り替えと、Enterprise管理者のポリシー確認が必要です。

何が発表されたか

GitHubは2026年10月19日付で、Copilotの一部モデルを廃止しました。廃止そのものは2026年9月18日に予告済みでした。対象はCopilot Chat、インライン編集、ask/agentモード、コード補完を含むほとんどのCopilot体験です。すべての体験とは書かれていません。

廃止されたモデルと、GitHubが示す代替は次のとおりです。

廃止されたモデル 推奨される代替
Gemini 3.7 Flash Gemini 3.8 Flash
GPT-5.5 / GPT-5.4 GPT-6.1 Sol
GPT-5.4 mini / GPT-5 mini GPT-6 Luna
Grok 4.5 Grok 4.7

廃止モデルを一覧から消す作業は利用者側では不要です。一方で、ワークフローや連携は対応モデルへ更新するよう求められています。Copilot Enterpriseでは、代替モデルを使うために管理者がモデルポリシーで有効化する必要がある場合があります。代替モデルの料金や提供地域は出典に記載なしです。

誰に関係するか

  • 開発者: Copilot Chatなどで旧モデルを選んで使っていた人は、代替モデルへの切り替えが必要です。
  • 企業のIT部門（Copilot Enterprise管理者）: 代替モデルのポリシーが無効のままだと、社員の画面に代替モデルが出ない可能性があります（推測）。
  • 自動化・連携を作っている人: モデル名を指定したワークフローや連携があれば、見直しの対象です。
  • 一般利用者: Copilotを使っていなければ影響は小さいです。

今日できること

  • 社内のワークフローや連携で、上の表の廃止モデル名を指定している箇所を探し、右列の代替モデルに書き換える。
  • Copilot Enterpriseの管理者は、Copilot設定のモデルポリシーで代替モデルが有効になっているか確認する。
  • 有効化したあと、VS Codeまたはgithub.comのCopilot Chatのモデル選択に代替モデルが表示されるか確かめる。
  • GitHub Enterpriseの契約で不明点があれば、担当のアカウントマネージャーに問い合わせる。

注意点

  • 廃止の対象はほとんどのCopilot体験とされ、例外となる体験の範囲は出典に記載なしです。
  • 代替モデルの料金・提供条件・日本での利用可否は出典に記載なしです。
