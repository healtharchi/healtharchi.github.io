GitHub、VS CodeのCopilot 9月更新を公表

何が発表されたか

GitHubは2026年10月1日、2026年9月に出荷されたVS Code v1.136からv1.140までのCopilot更新をまとめて公表しました。テーマは、実装からプルリクエストのマージまでをエージェントで進めやすくすることです。主な追加は次のとおりです。

  • automations: 時間単位・日単位・週単位のスケジュール、またはオンデマンドでタスクを実行できます（プレビュー）。
  • agent merge: 作業中のセッションで有効にすると、エージェントがレビュー指摘、失敗したチェック、マージ競合、ワークフローの再実行に対応します（プレビュー）。
  • HydraFusion: モデルピッカーで選ぶと、作業に使うモデルとワークフローを自動で選びます。対象者向けのリサーチプレビューです。
  • プルリクエスト作成: Copilot・Claude・Codexのエージェントセッションから、Agentsウィンドウでフォームを開けます。
  • Dev Containerセッション: SSH・Tunnel・WSLホストでも使えます。
  • GitHub文脈の添付: IssueやプルリクエストをAdd Contextから、またはURL貼り付けで添付できます。

誰に関係するか

  • 開発者: VS CodeのAgentsウィンドウでCopilotを使っている人に直接関係します。定型作業の定期実行やPR対応の自動化が試せます。
  • 開発チームのリーダー: レビュー対応やチェック失敗への対応をエージェントに任せる運用を検討する材料になります。
  • それ以外の読者: 影響は小さいです。

注意点

  • automationsとagent mergeはプレビューで、HydraFusionはリサーチプレビューです。
