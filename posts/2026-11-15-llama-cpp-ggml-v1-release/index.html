llama.cppとggml、v1.0.0を公開

ローカルLLM基盤のllama.cppとggmlがv1.0.0を公開。今後はAPI・ABIの非互換をメジャーバージョンの更新で示す方針です。組み込み先の開発者が依存バージョンを見直す材料になります。

何が発表されたか

Hugging Face の ggml-org チームが、llama.cpp（libllama）と ggml（libggml）のライブラリを v1.0.0 としてリリースしました。2026年11月13日付の公式ブログでの発表です。

  • 今後、llama.cpp と ggml は API と ABI の非互換をメジャーバージョンの更新で示す方針です。
  • バージョンの規則は、./include 内の公開 C API への破壊的変更が MAJOR、後方互換な機能追加・バックエンド更新・モデル対応・API 追加が MINOR、API 変更のないバグ修正が PATCH です。
  • 配布経路として、Docker、Debian、Homebrew、conda-forge、MacPorts、Winget、XCFramework などが表に示されています。
  • llama.cpp は 150 を超えるアーキテクチャのバリエーションに対応していると説明されています。

出典によると、プロジェクトは開始から 3.5 年が経ち、多くの下流アプリケーションが依存する段階になっています。今回の方針は、そうした開発者に向けて互換性の境界を分かりやすくするものです。

誰に関係するか

  • 開発者: llama.cpp や ggml を自社アプリに組み込んでいる場合は、アップデート時に非互換の有無をバージョン番号で判断しやすくなります。
  • パッケージ管理者: 出典の配布経路の表に、自分が扱うパッケージ形態が載っているか確認できます。
  • 企業のIT部門・一般利用者: 具体的な影響は、出典に記載されていません。

  • llama.cpp や ggml に依存している場合は、依存するバージョンの指定を見直す。今後は API・ABI の非互換がメジャーバージョンの更新で示されます。
  • 出典の配布経路の表（Docker、Homebrew、conda-forge、Winget など）で、自分の環境に合う入手方法を確認する。
