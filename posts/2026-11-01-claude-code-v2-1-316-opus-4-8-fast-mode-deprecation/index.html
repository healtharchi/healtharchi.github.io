Claude Code、Opus 4.8のfast mode廃止

AnthropicがClaude Code v2.1.316を公開。Opus 4.8のfast modeは2026年11月30日に削除されエラーになるため、該当利用者はOpus 5.5への移行判断が必要です。新しい環境変数も追加。

何が発表されたか

Anthropic は 2026年10月31日、Claude Code の新版 v2.1.316 を GitHub で公開しました。今回は新機能より、期限のある変更が中心です。

  • fast mode の廃止予告: Opus 4.8 の fast mode は 2026年10月30日付で非推奨になり、2026年11月30日に削除されます。削除後はエラーになり、標準の Opus 4.8 へは切り替わりません。移行先は Opus 5.5 です。
  • 新しい環境変数: ultrathink を無効にする CLAUDE_CODE_DISABLE_ULTRATHINK と、サブエージェントの effort を指定する CLAUDE_CODE_SUBAGENT_EFFORT。
  • Claude apps gateway の管理機能: グループ共有の月次予算など、管理者向けの設定が増えました（詳細は次節）。

誰に関係するか

  • Opus 4.8 の fast mode を使っている利用者: 最も影響が大きい層です。2026年11月30日以降はエラーになるので、期日前の判断が必要です。高速化を続けたい場合の移行先は Opus 5.5 です。
  • 開発者: ultrathink を止めたい場合や、サブエージェントの effort をセッションから継承させず自分で決めたい場合に新しい環境変数が使えます。CLAUDE_CODE_SUBAGENT_EFFORT は、他に指定が無いときの effort を決めます。macOS と Linux で Claude Code が自ら終了したあとにシェルコマンドが動き続ける不具合や、–restricted セッションで、Read の許可ルールに含まれる作業ディレクトリ外のファイルがアップロードされる不具合も直っています。
  • 企業のIT部門・Claude apps gateway の管理者: 利用者ごとの上限に加えて、グループ共有の月次予算（pooled_budget）と、一致する方針をすべて重ねて適用する managed.policy_mode: layered で統制できます。Amazon Bedrock 上流には、ガードレールの prompt attacks フィルタが求める入力タグを付ける guardrail.input_tagging が加わりました。Team と Enterprise のログインでは、Anthropic の API から取得したサーバー管理設定が承認プロンプト無しで適用されるようになった点も押さえておく必要があります。
  • Amazon Bedrock / Vertex AI 経由で使う組織: sonnet・opus・haiku の別名で最新モデルがまだ使えないとき、古いモデルへ切り替わらずセッション途中でエラーになる不具合が直りました。Bedrock のガードレールが求める入力タグをゲートウェイ側で付けられるようになった点も関係します。
  • VS Code 拡張・クラウドセッションの利用者: VS Code 拡張ではターミナル無しにチャットパネルから Claude apps gateway へサインインできるようになりました。クラウドセッションでは、MCP サーバーが求めるフォームに入力または辞退できるカードが付きます。

今日できること

  • Opus 4.8 で fast mode を使っているか確認します。使っているなら、2026年11月30日より前に Opus 5.5 へ移行するか、fast mode 無しで続けるかを決めます。削除後は標準の Opus 4.8 へフォールバックしません。
  • ultrathink キーワードを使わせたくない環境では、環境変数 CLAUDE_CODE_DISABLE_ULTRATHINK を設定します。
  • サブエージェントの effort をセッションから継承させたくない場合は、環境変数 CLAUDE_CODE_SUBAGENT_EFFORT を設定します。
  • Claude apps gateway を運用している管理者は、spend limits admin API の pooled_budget でグループ共有の月次予算を設定できます。

注意点

  • fast mode の非推奨は Opus 4.8 だけが対象です。他のモデルについての記載は出典にありません。
  • Claude apps gateway、VS Code 拡張、クラウドセッション、Code Review に関する項目は、それぞれの環境を使っている場合に限ります。Code Review では、分析ページに重大度別の指摘件数を示すカードが追加されています。
  • 料金、提供地域、日本での利用条件は出典に記載なしです。
