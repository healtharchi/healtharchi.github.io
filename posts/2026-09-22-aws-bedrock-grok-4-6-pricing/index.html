Bedrock、Grok 4.6を提供 入力$2.00/1M

AWSがxAIのGrok 4.6をAmazon Bedrockで提供。入力1Mトークンあたり$2.00から、Priority・Flexの料金倍率、窓口ごとの機能差、日本での利用可否が不明な点を整理します。

何が発表されたか

AWS は 2026年9月21日のブログで、xAI の Grok 4.6 を Amazon Bedrock で提供していると案内しました。Bedrock での提供開始は 2026年8月18日です。

  • コンテキスト（一度に渡せる入力の長さ）は 500K トークンです。
  • 推論量は low / medium / high / xhigh の4段階で、既定は low です。
  • 入力はテキストと画像、出力はテキストのみです。
  • 窓口（エンドポイント）は2つあります。bedrock-mantle ではモデルIDが xai.grok-4.6、bedrock-runtime では us.xai.grok-4.6 か global.xai.grok-4.6 です。
  • API は Responses・Chat Completions・Converse に対応し、Invoke API は非対応です。
  • bedrock-mantle は us-west-2 で提供されます。bedrock-runtime は同一リージョン内の推論が無く、推論プロファイル（複数リージョンへ振り分ける設定）経由で呼び出します。

誰に関係するか

  • 開発者: 窓口で使える機能が違います。bedrock-runtime では Structured outputs（JSON形式の出力指定）が非対応です。構造化出力に頼る処理は窓口選びに注意が必要です。
  • 企業のIT部門: Geo（us.xai.grok-4.6）は US リージョン、Global（global.xai.grok-4.6）は世界に振り分けます。IAM の権限はプロファイルごとに付ける必要があります。
  • 日本の利用者: 日本のリージョンから使えるかは出典に記載なしです。Global はアジア太平洋を含む地域から使えるとされています。
  • OpenAI・Anthropic・Google の API だけを使う人: 影響は小さいです。

今日できること

  • Bedrock コンソールで、使う予定のリージョンで Grok 4.6 が使えるか確認する。
  • bedrock-runtime を使うなら、IAM ポリシーに us.xai.grok-4.6 と global.xai.grok-4.6 を個別に書く。片方の許可ではもう片方は使えません。
  • Grok 4.6 のモデルカードでリージョン一覧と機能表を、Amazon Bedrock の料金ページで単価を確認する。
  • 試用で作った long-term の Bedrock API キーは、使い終えたらコンソールで削除する。

注意点

料金は 2026年9月21日の AWS ブログ記載時点のもので、変わる可能性があります。

  • 入力1Mトークンあたり: Global は $2.00、Geo（US）は $2.20 です。
  • サービスティア: Priority は Standard の1.75倍、Flex は0.5倍です。出典の例では、Standard（in-Region）の $2.20 が Priority で $3.85、Flex で $1.10 になります。
  • キャッシュ済みの入力は、標準の入力単価のおよそ4分の1で課金されます。
  • xAI 自身の価格は入力 $2・出力 $6（1Mあたり）からで、fast 版はその2倍です。Bedrock での出力単価は出典に記載なしです。
  • 出典には xAI が公表したベンチマーク値もありますが、xAI 自身の数値のため本記事では性能の比較をしません。
