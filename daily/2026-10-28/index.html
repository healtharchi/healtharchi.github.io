3. GitHub Copilot assisted permissions generally available

GitHub（2026-10-26） ／ 判定: ○ 試す価値あり ／ 重要度 3/5 ／ 提供: 一般提供・日本: 不明

GitHub Copilot の assisted permissions が GitHub Copilot CLI、GitHub Copilot app、Visual Studio Code で一般提供になった。Copilot がコマンド実行・ファイルシステムのパスへのアクセス・URL を開く許可を求める際に大規模言語モデルが要求を評価し、明らかに安全と分類された要求は自動で進み、それ以外は利用者の承認が必要になる。企業管理者向けに Allow All の禁止や既定モードの指定などの制御も用意された。

  • 提供条件: GitHub Copilot CLI・GitHub Copilot app・Visual Studio Code が対象。企業ではポリシーで Assisted が無効化されている場合がある。
  • 関係する人: GitHub Copilot のエージェント機能を使う開発者、企業の IT 管理者・セキュリティ担当者
  • 今日できること: GitHub Copilot CLI では /permissions を実行して assisted を選ぶ ／ GitHub Copilot app ではモードピッカーの Tool permissions から、Visual Studio Code では permissions picker から Assisted を選ぶ ／ 企業管理者は enterprise-managed settings で Allow All を禁止しつつ Assisted を残すか、Assisted を無効にするかを決め、新規セッションの既定モードを設定する
  • 出典: https://github.blog/changelog/2026-10-26-github-copilot-assisted-permissions-generally-available

  • 関係する人: GitHub Copilot SDK でエージェントや自動化サービスを作る開発者、組織の GitHub 管理者・オーナー
  • 今日できること: GitHub App に読み取り専用の Copilot Requests 組織権限を付け、組織にインストールして、短期の installation access token を Copilot SDK に渡す ／ 組織オーナーは AI usage CSV レポートの app_client_id でアプリ別の利用量を確認する ／ 不要になったアプリは一時停止かアンインストールでアクセスを止める
