1. More ways to request and configure Copilot code reviews

GitHub（2026-09-23） ／ 判定: ○ 試す価値あり ／ 重要度 3/5 ／ 提供: 一般提供・日本: 不明

GitHub は Copilot code review の個人設定ページを Copilot Business・Enterprise を含むすべての Copilot プランに広げ、自動レビューと既定のレビュー強度（Lite / Balanced）を設定できるようにした。あわせて、エンタープライズ管理者が組織所有リポジトリ向けの既定レビュー強度を一括設定できるようになった。いずれも一般提供（GA）。

  • 提供条件: 個人のcode review設定ページはすべての Copilot プラン（Business・Enterprise を含む）。エンタープライズ既定レビュー強度は権限のあるエンタープライズ管理者向けで、組織所有リポジトリに継承（組織・リポジトリで上書き可）。
  • 関係する人: 開発者、企業のIT部門、GitHub Copilot 管理者
  • 今日できること: プロフィールの Copilot settings にある「code review」ページで、自動レビュー（新しい push・ドラフトのプルリクエストを含む）の有効化を決める ／ 同ページで既定のレビュー強度を Lite か Balanced に設定する ／ エンタープライズ管理者は企業全体の既定レビュー強度（Lite、Balanced、GitHub の既定）を設定し、組織・リポジトリ側の上書きの有無を確認する
  • 出典: https://github.blog/changelog/2026-09-23-copilot-code-review-more-ways-to-request-and-configure-reviews
