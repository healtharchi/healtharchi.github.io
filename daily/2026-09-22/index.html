4. Simplifying Model Serving Across Multiple GPUs with NVIDIA TensorRT Multi-Device Integration in NVIDIA Dynamo-Triton

NVIDIA（2026-09-21） ／ 判定: × 無視でOK ／ 重要度 2/5 ／ 提供: 一般提供・日本: 不明

NVIDIA は、1 つの TensorRT ネットワークを NCCL で複数 GPU にまたがって実行する TensorRT multi-device inference（TensorRT 11.0 から正式対応）を、NVIDIA Dynamo-Triton 26.07 の TensorRT バックエンドで使えるようにしたと解説した。1 つの KIND_MODEL インスタンスが複数 GPU を持ち、アプリケーションは 1 つの gRPC エンドポイントを呼ぶだけでよい。Cosmos 3 Nano の動画生成を例に、8 GPU で生成時間が短縮された測定結果を示している。

  • 今日できること: NGC から NVIDIA Dynamo-Triton 26.07 をダウンロードし、自環境で結果を再現する ／ Dynamo-Triton TensorRT backend multi-device guide で設定方法を確認する ／ GPU 追加と遅延短縮の損得を、自社の SLO と運用コストで評価する（本ベンチマークはスループットやコストを測っていない）
