1. Get Started with GPU-Accelerated DuckDB Analytics Using the Sirius Core Extension

NVIDIA（2026-11-23） ／ 判定: ○ 試す価値あり ／ 重要度 3/5 ／ 提供: 一般提供・日本: 不明

NVIDIA と DuckLabs が、GPU-native の SQL engine である Sirius を DuckDB の core extension として公開した。INSTALL sirius; と LOAD sirius; の 2 つの SQL コマンドで、SQL を書き換えずに対応する分析クエリを NVIDIA GPU で実行でき、対応していない機能を含むクエリは DuckDB の CPU engine に戻る。TPC-H 由来のクエリを使った cold run の比較で、調整済みの 2 GPU 構成が 3.25x〜5.50x の高速化を示したと報告している。

  • 提供条件: DuckDB の core extension として公開。DuckDB 2.0 と、対応するドライバーの入った NVIDIA GPU が必要。GPU で実行されるのは対応するクエリで、対応していない機能を含むクエリは DuckDB の CPU engine に戻る。
  • 関係する人: DuckDB を使うデータエンジニア、データ分析基盤の担当者、NVIDIA GPU を持つ開発者
  • 今日できること: DuckDB 2.0 と対応するドライバーの入った NVIDIA GPU がある環境で、INSTALL sirius; と LOAD sirius; を実行して拡張を入れる（およそ 700 MB） ／ 出典の手順どおり、INSTALL tpch; LOAD tpch; CALL dbgen(sf=0.01); CHECKPOINT; で小さな試し用データを作り、lineitem への集計クエリを実行する ／ Sirius のリポジトリにある benchmark runner・query definitions・configuration details・setup instructions で、自分のハードウェアでの性能を確かめる
  • 出典: https://developer.nvidia.com/blog/get-started-with-gpu-accelerated-duckdb-analytics-using-the-sirius-core-extension/
