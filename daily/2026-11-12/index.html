  • 料金: 入力100万トークンあたり$0.10、出力トークンは$0。Google AI Studio でプロトタイピング用の API 無料枠あり。共有入力はリクエストごとに1回課金され、質問ごとに指示と criteria のトークンが加算。出力トークン・思考トークン・音声文字起こし・OCR の別料金は無い。
