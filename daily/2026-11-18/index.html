GitHub（2026-11-17） ／ 判定: △ 様子見 ／ 重要度 3/5 ／ 提供: プレビュー・日本: 不明

GitHub Copilot app が Azure DevOps のリポジトリ、GitHub Enterprise Server、サインイン済みのブラウザでの作業に対応した。Azure DevOps 連携とブラウザ操作はパブリックプレビュー、GHES 対応は一般提供になった。

  • 提供条件: Azure DevOps 連携とブラウザ操作はパブリックプレビュー。GHES 対応は一般提供（GitHub Copilot app 1.2.0 以降）。Azure DevOps と GHES ではクラウドセッションは使えない。
  • 関係する人: 開発者、企業のIT部門
  • 今日できること: Azure DevOps を使うチームは、GitHub Copilot app の Settings > Experimental で Azure DevOps integration をオンにし、Accounts > Add account で Microsoft アカウントを追加する ／ ブラウザ操作を試す場合は、Chrome 用 GitHub Copilot 拡張機能を入れ、Settings > Computer Use で Enable Computer Use と Enable Browser Use をオンにする ／ GHES を使う組織は、GitHub Copilot app を 1.2.0 以降に更新し、Settings > Accounts > Add account で GitHub Enterprise Server を追加する
